Acerca de

¿Qué es esta Pokédex?

Esta Pokédex es una aplicación web que te permite buscar información detallada sobre cualquier Pokémon: su imagen oficial, tipos, altura, peso, habilidades y estadísticas base.

Fue creada como un proyecto de aprendizaje de desarrollo web, usando HTML, CSS y JavaScript puro, sin ninguna librería externa.

¿De dónde vienen los datos?

Toda la información proviene de PokéAPI, una API pública y gratuita que contiene datos de más de 1,000 Pokémon de todas las generaciones.

Cada vez que buscas un Pokémon, la aplicación hace una petición a pokeapi.co y muestra los datos en tiempo real.

Tecnologías usadas

HTML — estructura de la página

CSS — estilos y diseño visual

JavaScript — lógica y conexión con la API

PokéAPI — fuente de todos los datos Pokémon

Google Fonts — fuentes Press Start 2P y Nunito
